# Campus Canteen Sales Analysis Using SQLite

## Project Overview
This project focuses on managing and analyzing campus canteen transactions using SQLite. It contains a dataset of 50 sample transactions and uses SQL queries to analyze student purchases, food categories, payment methods, transaction statuses, and sales amounts.

## Objectives
- Create and manage a structured canteen transaction database.
- Analyze student purchasing patterns.
- Identify transactions based on food categories and payment methods.
- Calculate total transactions and completed sales.
- Practice SQL queries for data retrieval and analysis.

## Technologies Used
- **Database:** SQLite
- **Language:** SQL
- **Platform:** Online SQLite Editor
- **Version Control:** GitHub

## SQL Concepts Used
- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- AND, OR, IN
- ORDER BY
- LIMIT
- COUNT(), SUM()
- GROUP BY
- PRAGMA

## Dataset
The project includes 50 sample canteen transactions containing student names, departments, food items, food categories, quantities, prices, transaction amounts, payment methods, statuses, and dates.

## Project Queries
The project contains 15 SQL queries covering data filtering, sorting, aggregation, payment method analysis, completed sales calculation, and table structure inspection.

## Conclusion
This project demonstrates basic SQL database management and data analysis skills through a practical campus canteen sales scenario. It provides hands-on experience with SQLite and helps develop foundational skills for data analytics.
